# BACKEND

Repositorio reservado para un componente backend.

## Estado del proyecto
La rama principal contiene únicamente este archivo de documentación. No se han añadido instrucciones de ejecución ni tecnologías supuestas para evitar describir funcionalidades que todavía no están presentes.

## Para completar el repositorio
- [ ] Añadir una descripción del propósito y de los consumidores de la API.
- [ ] Documentar lenguaje, framework y versión requerida.
- [ ] Documentar configuración mediante variables de entorno sin incluir valores secretos.
- [ ] Añadir instrucciones de instalación y ejecución.
- [ ] Documentar endpoints, autenticación y códigos de error.
- [ ] Añadir pruebas automatizadas y un comando de verificación.
- [ ] Incluir un archivo de ejemplo de variables de entorno y un `.gitignore`.

## Seguridad
No subas claves, tokens, contraseñas, datos de clientes ni archivos de configuración de producción. Usa el gestor de secretos del entorno de despliegue.
